# baitalmataem.com — النسخة الأولى (MVP)

موقع بيت المطاعم | Bait Al Mataem — منصة سعودية متخصصة في تأسيس وتشغيل وتطوير وتقييم وبيع وشراء المطاعم، وفرص العقارات التجارية المناسبة لنشاط المطاعم. مبني بـ Next.js 14 (App Router) وTypeScript وTailwind CSS.

**قبل أي شيء آخر، اقرأ `docs/PROJECT_STATUS.md`** — يوضح بصراحة كاملة أي جزء حقيقي وجاهز للتشغيل، وأي جزء معاينة تفاعلية بانتظار ربط قاعدة بيانات.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000` (سيُعاد توجيهك تلقائيًا إلى `/ar`).

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local` واملأ القيم المتاحة لديك فعليًا. لا تضع فيه أي رقم أو مفتاح وهمي — اتركه فارغًا حتى تتوفر القيمة الحقيقية.

## البنية

راجع `docs/PROJECT_STATUS.md` لخريطة الملفات الكاملة، و`docs/SUPABASE_SETUP.md` لخطة ربط قاعدة البيانات في المرحلة القادمة.

## النشر

بعد التأكد أن المشروع يعمل محليًا بدون أخطاء، اتبع `DEPLOYMENT.md` خطوة بخطوة لرفعه على GitHub، نشره على Vercel، وربط دومين `baitalmataem.com`.
